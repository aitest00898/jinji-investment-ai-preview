# 金雞 Investment AI — Contextual preview

觸控式投資工具的靜態互動提案。所有場地、參與者、代養主、比例、金額與營運資料均獨立虛構；沒有匯入、匿名化或搬移真實附件。

## 三個主要入口

- **總覽**：今年 Pool 盈虧、最佳／最差單水、獲利水比例、最近結算與目前配置風險。
- **收益**：在同一組場地、年度、月份與參與者條件下切換「收益／配置」。收益可分開查看分配盈虧與支出後淨收入；配置提供個人內部分配、換算整場比例、生效水次及可拖曳的比例時間軸。
- **營運表現**：場地／代養主的育成率、FCR、有效樣本與必要輸入完整度。正式評分錨點未完成，因此不顯示空白 0–100 分或虛構成熟度。

資料治理在右上角的狀態入口。異常內容包括比例衝突、財務列未對應水次、風險缺欄、匯入異常及補充營運資料過舊；各場只提示相關問題。Excel 完整欄位對照保留在這個入口中。

## 上下文與互動

場地列可橫向捲動；收益與配置共用條件。切頁、切視角、關閉明細及重新載入保留篩選與閱讀位置。單水在手機 bottom sheet／桌面置中浮層中原位展開，可切收益明細／比例快照、左右滑動水次、下拉把手收合。左緣右滑可返回上一個查看狀態；導航與明細按鈕提供非手勢操作。

比例時間軸包含已結算快照、明確配置生效點與所選期間末配置。每筆歷史分配使用自己的快照，不以目前配置回算。三位參與者可等分、不等分，也可合計小於 100%；剩餘 Pool 比例明確顯示為「未分配」，不自動正規化或分攤。

長按主要數字或選擇旁邊的解讀入口，開啟帶有目前場地、期間、參與者、金額口徑與所選水次的 Contextual AI Lens。回覆由本地計算的虛構資料產生，提供可回到單水的證據。比例影響只是相同基底的比較，不預估收益或改寫歷史。

外框與主導航固定，內容分區捲動。開啟頁面／浮層不自動聚焦輸入欄位。網頁禁用內容縮放手勢；系統強制無障礙縮放由瀏覽環境決定。

## 規模與邊界

18 個場、6 位代養主、2023–2026 四年、206 筆已結算水次、39 個比例版本、48 筆跨年度發錢，另有 18 個進行中水次及 5 類異常情境。2026 年有 53 筆已結算水次。

主要財務來源可獨立支援收益查詢；缺營運輸入不補零、不阻擋財務。來源「玩家」指三位參與者；「場占比」與參與者 Pool 內比例是兩層比例，參與者合計可小於 100%，剩餘部分保留為未分配；其他來源比例欄位仍各自保留 provenance。示範依結算日歸屬，正式版依權威來源日期／期間保存，不強迫重新解釋會計日期語意。

未串接 Cloudflare AI、LINE Messaging API、資料庫或正式資料，亦未提供安裝／離線功能。LINE 示範不傳送訊息，開啟 PWA 時攜帶相同查詢。更正只修改目前頁面的虛構金額，重新整理即還原。
