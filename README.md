# 金雞 Investment AI — Design preview

PWA 與 LINE 查詢介面的靜態互動設計提案。所有場地、代養主、業務與金額皆為人工虛構範例。

可切換 PWA／LINE、紙白／墨黑、朱砂／橄欖；可操作期間查詢、結算明細、風險與編輯確認流程。

外框與主要導航固定，只有內容區與明細浮層捲動。手機導航位於底部，桌面位於頂部。網頁設定固定 viewport 比例、停用內容縮放手勢；開啟頁面或浮層不自動聚焦輸入欄位，編輯仍需業務主動點入。瀏覽器或系統的強制無障礙縮放仍由該環境決定。

「收益」是主要入口，可切換 2024–2026 年／全部年度、月份、場地／代養主旗下場地，以及 Pool／三位業務分配。月份可橫向滑動，每筆結算可原位展開；切頁後保留篩選與閱讀位置。歷史資料亦全部人工虛構，示範依結算日歸屬，未將發錢日或支出後淨收入混為同一口徑。

「投資」可依場地或業務查看目前 Sales Pool 占整場比例、三位業務各自的 Pool 內分配、換算後占整場比例與生效水次。比例歷史分開呈現當時配置：虛構場 B 目前 25%，舊水仍採 20%。「玩家」已確認指三位業務；來源「各場總股份」、「玩家列比例」、「場占比」獨立保留，映射未確認的欄位不代填數值。

單水明細列出結算日、發錢日、總盈虧、分配盈虧、支出費用、淨收入、三位業務金額、合計與備註，並顯示該水比例快照。收益頁可分開查閱費用前分配盈虧與費用後淨收入，「完整期間帳務」列出目前範圍所有財務欄位累計。新增發錢日及支出也完全由人工虛構；日期歸屬與正式帳務映射仍待確認，未改動首頁 Pool 盈虧定義。資料頁提供 Excel 原欄位與顯示位置對照。

「評分」分成場地與代養主頁籤，提供育成率及 FCR 兩個獨立子分數欄位、原始指標、各自有效樣本及跨場證據。指標由虛構的分子／分母加權計算；缺資料不計為 0。正式雞種評分錨點與成熟度門檻尚未確認，因此分數保留「評分基準待建立」，未填入臆測分數。評分明細可直接前往相同範圍的歷史收益。

明細在原位開啟：手機使用底部浮層，桌面使用置中浮層。下拉頂部把手、點背景、關閉鍵或 Esc 可收合，保留捲動位置與鍵盤焦點。單水明細支援左右滑動及上一水／下一水操作。

此版本未串接 Cloudflare AI、LINE Messaging API、資料庫或正式資料，亦尚未提供可安裝與離線功能。AI 解讀使用本地示範回覆；編輯只影響目前頁面，重新載入即還原。

## Preview locally

```sh
python3 -m http.server 4373 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4373/。不需要 Node、套件安裝或 API key。

## GitHub Pages

儲存庫的 Pages source 設為 GitHub Actions 後，推送至 `main` 會觸發部署。流程只發布 `index.html`、`build.json` 與 `.nojekyll`，並在網頁及 `build.json` 寫入來源 commit SHA。

本預覽不包含需求規格庫、正式資料或匯入檔案。
